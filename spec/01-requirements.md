### Open-Meteo 規約確認結果 (2026-11-23 時点、ページに更新日表記なし)
- 無料 API は非商用限定。非商用の例: 「サブスクリプションや広告のない、個人または非営利のウェブサイト/アプリ」。寄付 (tip jar) は可。商用の例: 「サブスクリプションや広告があるアプリ」「商用製品・販促活動」。→ 広告・課金なしの無料公開アプリは該当する想定。ただし営利事業者が公開する場合の扱いは明記がなく解釈の余地がある (不安なら info@open-meteo.com に問い合わせ)。
- 無料枠の上限: 1日 10,000 回 / 1時間 5,000 回 / 1分 600 回 / 月 300,000 回。制限は **IP とアプリ単位**。濫用する IP・アプリは予告なくブロックされ得る。
- 無料枠は API キー不要。商用プランは専用エンドポイント + API キー (料金はページに記載なし)。
- データは CC BY 4.0。**帰属表示が必須**: データを表示する場所の近くにリンク「Weather data by Open-Meteo.com」(https://open-meteo.com/)。再配布・保存は CC BY 4.0 の範囲で可、キャッシュ/保存に関する個別規定なし。
- 規約は掲載と同時に変更され得るため、公開前に再確認する。

### アプリ基本情報・バックアップ (確定: 2026-11-23)
- アプリ名: 頭痛ダイアリー
- minSdk: 26 (Android 8.0)。targetSdk は着手時点の Google Play 要件に合わせる (雛形タスクで確定)。
- パッケージ名: `io.github.abe_ma.headachediary` (2026-11-23 決定。GitHub ユーザー名 abe-ma のハイフンは applicationId で使えないためアンダースコアに置換。公開後は変更不可)。
- NFR-200 バックアップは Android の自動バックアップ (Google アカウント経由) を使う。Room DB と設定を対象に含める。ユーザーはデータをクラウドに保存することになるため、プライバシーポリシーとストア申告に明記する。新端末への復元後も通知の予約は復元時に再設定する。
- NFR-201 アプリ独自のクラウド同期・アカウント登録は行わない。CSV は閲覧・提出用で、復元手段としては扱わない (取り込み機能は作らない)。

### 気圧まわりの非機能・制約
- NFR-100 外部送信するのは、登録地域の代表緯度経度 (小数1桁に丸めた値) と取得期間のみ。発作記録・服薬などの健康データ、端末識別子は送らない。IP アドレスは通信の性質上 Open-Meteo に届く。
- NFR-101 気象 API 呼び出しは Repository インターフェースの裏側に隔離し、提供元の差し替え (有料プラン・他社 API) を可能にする。
- NFR-102 API キーは使わない。自前サーバは置かない (端末から直接呼ぶ)。
- NFR-103 プライバシーポリシーに外部送信の内容を明記する。Google Play のデータセーフティ申告を行う。
- NFR-104 アプリは気圧と頭痛の関連について医療的な助言・診断をしない (記録と可視化まで)。

### 薬のプリセット (暫定。静的データとしてアプリに持つ。頓服薬のみ)
商品名で選び、成分名を併記する (バファリンはシリーズで成分が異なるため)。選択肢は表示用で、成分・用量に基づく助言や警告はしない (NFR-104)。
一覧の過不足はユーザー確認済み (2026-11-23)。薬名・成分は manager の知識に基づくため、実装前に公的情報 (PMDA 等) で照合する。

- バファリン (シリーズにより成分が異なる)
- ロキソプロフェン: ロキソニン

処方薬 (片頭痛の頓服)
- ナプロキセン (表示名: ナプロキセン（ナイキサン）。2026-11-23 ユーザー指示。ブランド単独名だと販売状況が不明なため)
- トリプタン系: リザトリプタン (マクサルト)、スマトリプタン (イミグラン)、ゾルミトリプタン (ゾーミッグ)、エレトリプタン (レルパックス)、ナラトリプタン (アマージ)

- 吐き気止めの頓服: ドンペリドン (ナウゼリン)、メトクロプラミド (プリンペラン)

漢方薬 (2026-11-23 ユーザー指示で追加。頭痛・気象病に用いられる代表的な処方。服用は頓服として記録する前提で、服用方法の指示や効能の主張はしない)
- 五苓散 (五苓散料、エキス剤)
- 呉茱萸湯

## リマインダー・通知 (確定: 2026-11-23。数値は暫定)

| ID | 要件 |
| --- | --- |
| FR-500 | **効果入力のリマインド:** 服薬を「未評価」で保存した場合、一定時間後 (既定 2 時間、設定で変更可) に通知し、タップで該当発作の効果入力画面を開く。入力済みになれば通知は取り消す。 |
| FR-501 | **気圧低下の通知:** 登録地域の予報で、翌日までに気圧が大きく下がる場合に通知する。判定: 予報の24時間以内の下降幅 ≥ しきい値 (既定 6 hPa、設定で変更可)。通知時刻は設定可 (既定 20:00)。1日1回まで。 |
| FR-502 | 気圧低下の通知文は事実のみ (例: 「明日、気圧が 7 hPa 下がる予報です」)。症状の予測や服薬の指示・助言はしない (NFR-104)。 |
| FR-503 | 各通知は設定画面で個別にオン/オフできる。通知権限 (Android 13+ の POST_NOTIFICATIONS) は、通知を有効にする操作の時点で要求する。拒否されても記録機能は使える。 |
| FR-504 | 気圧データの取得に失敗して予報が古い場合、FR-501 の通知は出さない (古い予報で誤通知しない)。 |

### 通知まわりの制約 (設計メモ)
- 時刻の厳密さは不要なため WorkManager (非正確) で実装する。正確なアラーム権限 (SCHEDULE_EXACT_ALARM) は要求しない。
- 端末再起動後も通知の予約を復元する。
