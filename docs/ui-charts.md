# 集計グラフの実装方針

## 選定: Compose Canvas で自作 (外部ライブラリは使わない)
- 必要な表現は「月別の棒グラフ」と「折れ線 (実線=取得済み / 破線=予報) + 発作マーカー + 現在線」の 2 つだけで、軽量。
- 外部のグラフライブラリは、(a) 破線の予報と縦のマーカーの重ね合わせ、(b) ダークテーマへの追従、(c) TalkBack 向けの説明、
  を細かく制御しにくく、依存・R8 ルール・ライセンス表示が増える。自作は Canvas + `rememberTextMeasurer` で約 200 行。
- 依存の追加なし (build への依頼なし)。

## 表現
- 色だけに頼らない: 予報は破線、発作は ▼ マーカー + 縦線、現在は点線。凡例は記号 + 文字。棒グラフは値を数字で表示。
- 色は MaterialTheme の配色から取るのでダーク対応。
- アクセシビリティ: グラフ全体に contentDescription (月別の件数一覧、気圧の最低・最高と発作件数)。事実のみで、解釈・助言は含めない (NFR-104)。
- 縦軸は最低 8 hPa の幅を確保する (わずかな変動を大きく見せない)。欠測 (3 時間超の間隔) は線をつながない。

## テスト
- 計算 (`ChartMath.kt`) はユニットテスト。描画そのものは Robolectric では検証できないため、実機/エミュレータでの目視が未確認事項。
